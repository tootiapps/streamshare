# Changelog

All notable changes to `@streamshare/service` will be recorded here.

- Define the explicit StreamShare service protocol v1 manifest and response contracts.
- Add runtime validation for manifests, results, navigation, playback variants, facets, and pagination.

- Add a machine-readable application compatibility matrix.
